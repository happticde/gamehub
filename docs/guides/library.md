# Manage your collection

Open **Library** (`/library`) to browse all imported digital games and saved physical games.

## Find a game

1. Enter a title in the library search.
2. Use platform, tag, developer, or publisher filters to narrow the results.
3. Choose your sort order and page size.
4. Open a game to inspect its details and platform entries.

On a small screen, open the filter dialog to reach the same filters.
The global search can open a game's details directly. Use the random-pick action to choose
a game from the current selection. **Statistics** (`/stats`) summarizes your collection.

## Understand a game's entries

A single game can show ownership on several platforms and include physical copies.
Its IGDB metadata describes the game, while platform entries describe where you own it.
Changing a cover match does not move platform ownership. Removing a physical copy does not
remove a digital purchase.

If an expected game is missing, check filters and ignored games before importing again.
Use [Missing games](troubleshooting.md#games-are-missing) for further checks.
