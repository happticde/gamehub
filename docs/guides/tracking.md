# Track progress and use tags

## Record play status and a rating

1. Open **Library** and select a game.
2. Choose the personal play status that reflects your progress.
3. Set a personal rating from one to five stars when you want to rate it.
4. Wait for the save to complete before leaving.

Provider playtime and personal status are separate. A game can have playtime without being marked
completed. Your manually chosen status is preserved through later syncs.

## Organize with tags

Open a game's tag controls to assign or create a custom tag, then check that the assignment is
saved. Custom tags are useful for groups such as games to play next or games played with friends.
Use library tag filters to find that group later.

Genre tags can also arrive from metadata enrichment. Enrichment updates its genre assignments
while preserving custom assignments. Removing a custom tag definition removes its assignments
from games; provider-created system tag definitions cannot be deleted.

## Ignore an entry

Use the game's ignored-state control for entries you do not want in normal collection views.
If a game seems to have disappeared, include ignored entries in the library filters and inspect
its ignored state before assuming the import deleted it.

## Protect personal changes

Use **Admin → Backup → Download JSON** to save tracking and tag assignments.
A CSV export is useful for a spreadsheet but cannot restore the complete collection.
See [Backup and restore](backup-restore.md).
