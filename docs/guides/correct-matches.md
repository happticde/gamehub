# Correct a game match

Use this when a game has the wrong cover, description, or metadata.
For duplicate games or misplaced platform ownership, use [Merge and split](merge-split.md).

## Choose the correct IGDB entry

1. Open the affected game's detail page.
2. Select **Fix Match**.
3. Search for the correct title. If you know its IGDB identifier, enter that identifier to narrow
   the search.
4. Review the candidate's title and edition before selecting it.
5. Confirm the replacement and wait for completion.
6. Check the game's cover, description, and other metadata.

An IGDB match correction changes metadata identity. It does not move Steam, GOG, PlayStation,
or Epic ownership between games.

## No suitable result

Try the base title without edition suffixes. If every metadata search fails, ask the host to
check IGDB configuration and use [Metadata troubleshooting](troubleshooting.md#covers-or-descriptions-are-missing-or-wrong).
Do not confirm a merely similar title to dismiss the dialog.
